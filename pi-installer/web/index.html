How to Install (2 commands only)
Open a terminal on the target machine Press Ctrl+Alt+T on Ubuntu, or search "Terminal" in apps.
Download the installer script This downloads the install script from the Pi to your machine.
Run the installer This installs everything automatically. The kernel build takes 30-90 minutes. The machine reboots when done.
sudo bash install.sh
Fully automatic: No further input needed. The script auto-detects the Pi, syncs the clock, installs all packages, builds the kernel, and reboots when done.
Connection Status
Pi installer online
What Gets Installed

Build tools & networking: iperf3, mptcpize, bmon, htop, tcpdump, nload, ethtool, traceroute, net-tools, iproute2
MPTCP Kernel: Custom mptcp_net-next kernel with 8 novel schedulers (Hybrid, CWL, EDF, LRTT, BLEST, ECF, RR, Redundant)
Go + mp-quic: Go 1.20.14 + mp-quic with MPQUIC schedulers (BWA, BWLS)
Dashboard: Multi-RAT Scheduler Dashboard (React frontend + Python backend)
